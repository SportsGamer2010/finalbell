# Content (editor-authored)

No `.uasset` / `.umap` files are generated by scaffolding. Required editor actions:

1. Create `Maps/Ring_P1` (or use a temporary engine map) and place:
   - `AFBRingBounds`
   - two `AFBBoxerCharacter` placeholders (or player start + AI spawn)
   - `AFBBroadcastCamera`
2. Create Enhanced Input assets and assign on `AFBBoxerCharacter` defaults:
   - IMC: Move (WASD / left stick), Jab, Cross, Guard
3. Set `GameDefaultMap` in `Config/DefaultEngine.ini` once the map exists.
4. Do not commit binary assets until Git LFS tracking is verified.
